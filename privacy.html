Privacy Policy

Effective date: November 21, 2026

This policy describes how Just One Variable Publisher (the "App") handles information when it accesses Google user data. The App is a private tool used only by the operator of the YouTube channel Just One Variable to manage that channel.

Data the App accesses

  • YouTube Data API (youtube scope): the channel's identity (channel ID, title, handle), uploading videos, setting their title, description, tags, privacy status, scheduled publish time and thumbnails, and reading the status of the channel's own videos.
  • YouTube Analytics API (yt-analytics.readonly, yt-analytics-monetary.readonly scopes): read-only performance reports for the channel's own videos, such as views and watch time.

How the data is used

The data is used only to upload and schedule the channel's own videos, confirm that they were published correctly, and measure their performance for the operator. It is not used for advertising, profiling, or any other purpose.

Storage and security

The OAuth refresh token is stored encrypted in a database on the operator's own computer. Video records and analytics results are stored in the same local database. No data is sent to any server other than Google's APIs.

Sharing

The App does not sell, rent, transfer or disclose Google user data to any third party.

Google API Services User Data Policy

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data is kept only as long as needed to operate the channel. Access can be revoked at any time from Google Account permissions; after revocation the App can no longer access the account, and the operator deletes the stored token from the local database.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
